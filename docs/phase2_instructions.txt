### 5. Required mathematical foundations

Explain the sequence of operations:

1. A sequence of token representations is projected to query, key and value vectors.
2. Query-key dot products represent compatibility scores.
3. Scores are scaled by the square root of key dimension.
4. A mask restricts disallowed attention locations.
5. Softmax converts allowed scores into normalized weights.
6. Weights form weighted sums of value vectors.

Include and explain the equations:

`S = QKᵀ / sqrt(d_k)`

`A = softmax(S + M)`

`O = AV`

where the causal additive mask M is zero on allowed entries and negative infinity on forbidden entries.

Explain that scaling reduces extreme attention logits associated with growing key dimensionality.

Differentiate:

- Q/K/V feature projections.
- Similarity scores.
- Normalized attention weights.
- Contextualized output representations.

Distinguish unmasked bidirectional attention from causal attention.

Do not falsely equate attention weights with explanations of semantic understanding.

### 10. Mask implementation

Implement causal masking explicitly using an upper-triangular forbidden-position mask or an equivalent method.

For a three-token sequence, the forbidden positions are:

- Row 1, columns 2 and 3.
- Row 2, column 3.
- No forbidden positions in row 3.

Use unambiguous naming such as `forbidden_mask`, where `True` means the key is blocked.

If you expose a user mask with another convention, document and test it. Avoid silently reversing boolean-mask meaning between call sites.

Apply masks **before** softmax.

Test that:

1. Forbidden positions produce zero weight.
2. Allowed weights sum to 1 when at least one key is available.
3. Future-token influence is excluded.
4. Different sequence lengths produce correct triangular structure.
5. Batch dimensions do not alter mask alignment.
6. Mask broadcast errors are detected.
7. A row with every key forbidden is not silently converted into NaNs or fabricated uniform attention.

Define an explicit policy for fully masked rows: reject them with a clear error or support a mathematically documented zero-output behavior. The ordinary causal self-attention case should always have at least the current token available.

Do not mask after softmax and renormalize as an undocumented substitute.
